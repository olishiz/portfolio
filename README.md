# Oliver Sim — VS Code Portfolio

A Visual Studio Code-inspired portfolio for Oliver Sim Choo Howe, a senior
full stack engineer based in Selangor, Malaysia.

The site presents Oliver’s experience across enterprise application
development, backend systems, cloud modernization, DevOps, and AI-enabled
solutions. It includes interactive themes, keyboard navigation, a command
palette, and a working terminal.

## Local development

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Production build

```bash
npm run build
```

The static export is written to `out/`. Pushing `main` deploys that export to
GitHub Pages at [olishiz.github.io/portfolio](https://olishiz.github.io/portfolio/).

## Keyboard shortcuts

- `Ctrl/Cmd + Shift + P` — open the command palette
- `Ctrl/Cmd + backtick` — toggle the terminal
- `G`, then `H/A/P/E/C/G/S` — navigate the portfolio
- `K`, then `T` — change the color theme
